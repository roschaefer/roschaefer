# Robert Schäfer

Freelance full stack developer working remotely across web applications, product engineering, and infrastructure. I invest additional time in open source and focus on maintainable software, strong test coverage, and modernizing fragile systems by simplifying delivery and operations while strengthening quality through code review, pair programming, and technical mentoring.

Authoritative profile: [roschaefer.de](https://roschaefer.de/)

## Selected Work

- [Dialogbank](https://github.com/tactilenews/dialogbank-app/): SvelteKit application for AI-assisted interviews and editorial publishing. I am helping replace a brittle workflow spread across Airtable, Voiceflow, and custom services with a single serverless application.
- [DreamMall](https://dreammall.earth/): Open-source social platform where I reworked delivery and infrastructure, replacing fragile manual deployments with self-managed Kubernetes on Hetzner and Terraform-based production-like preview environments.
- [beteon](https://www.auteon.com/): Automotive aftermarket software. We migrated an Electron desktop application to a cloud platform and increased the number of connected wholesalers from 3 to 240.
- [100eyes](https://tactile.news/): Platform for audience engagement and crowd-based reporting in journalism, integrating WhatsApp, Telegram, Signal, Threema, and email for direct 1:1 communication between journalists and their communities.
- [Ocelot.social](https://github.com/Ocelot-Social-Community/Ocelot-Social): Community-built open-source social network. As Technical Lead, I worked on product architecture, GraphQL APIs, Neo4J in production, Kubernetes operations, onboarding contributors, and reviewing most contributions.
- [roschaefer.de](https://roschaefer.de/): My bilingual portfolio and resume site, built from a shared content source for the web, printable PDFs, and standards-compliant `resume.json`.
